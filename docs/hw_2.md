## Данные и конфиденциальность

Документы - внутренние страницы Confluence, поэтому в репозитории их нет. Ноутбук читает их из локальной папки продукта (`REQASSIST_DIR`) и выводит только агрегаты; документы обезличены как `doc_01`..`doc_06`, единственный пример структуры замаскирован. `summary.json` хранит SHA-256 исходных файлов: по хешу нельзя восстановить содержимое, но можно проверить, что выводы получены на тех же данных.

## Ветки

Ветка `hw_2` основана на `hw_1`. Пока PR ДЗ №1 не слит, база PR ДЗ №2 - `hw_1`, чтобы в ревью были только изменения второго задания. Если `hw_1` меняется по замечаниям ревью:

```bash
git fetch origin
git switch hw_2
git merge origin/hw_1
```

После слияния ДЗ №1 база PR ДЗ №2 переключается на `main`, diff проверяется заново.
